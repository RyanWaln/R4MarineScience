## This Repository is for coding work in MB5370 Techniques in Marine Science Module 2 using Rstudio.

Code covers:
- How to standardize text and dates across files
- Piping 
- Mutating data
- Handling NA values
- Plotting StDev and StError
- Saving tables and Figures
- Pivoting data to move around rows and columns in tables
- Separating and uniting tables or specific columns
- Reformatting larger data sets to fit with smaller ones
  
Datasets used:
- Palmer Penguins data set to explore morphological varriation across 3 species on 3 different islands
- Unpublished Ross River estuary fish surveys to determine if changing enviornmental factors like salinity are affecting fish species distributions
